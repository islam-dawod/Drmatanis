# DMC – Smile Design & Cosmetic Dentistry — Landing Page

דף נחיתה ממוקד לפרסום בגוגל בנושא **אסתטיקת שיניים**, עבור מרפאת **DMC – Dr. Moeen Aesthetics** בהובלת ד״ר מטאנס מועין.

## מבנה הדף
1. **Hero** – Smile Design & Cosmetic Dentistry + כפתורי "קביעת ייעוץ" ו-WhatsApp
2. **גלריה** – חיוכים וטיפולים (תמונות מקוריות מאתר המרפאה)
3. **למה DMC?** – עיצוב חיוך בהתאמה אישית · טכנולוגיה מתקדמת · צוות מקצועי · ליווי אישי
4. **הכירו את ד״ר מטאנס** – תמונה מקצועית + תקציר
5. **ביקורות** – קישור לחוות הדעת האמיתיות באתר המרפאה
6. **יצירת קשר** – טופס קצר (שם + טלפון) שנשלח ישירות לוואטסאפ המרפאה

## פרטים טכניים
- HTML/CSS/JS סטטי בלבד — ללא תלות בשרת.
- RTL מלא, רספונסיבי, כפתור WhatsApp צף.
- הטופס פותח שיחת WhatsApp עם פרטי הליד (`wa.me/972723945160`).
- כל התמונות ב-`assets/` נלקחו מאתר המרפאה הרשמי.

## הפעלה מקומית
פתחו את `index.html` בדפדפן, או הריצו שרת סטטי:
```bash
python -m http.server 8000
```
